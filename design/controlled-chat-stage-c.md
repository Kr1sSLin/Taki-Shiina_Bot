# 阶段 C：受控聊天与文字体验

日期：2026-10-17，北京时间。依据 PRD-03 v0.3、PRD-08 v0.3 和现有阶段 A/B 实现。本次完成本地代码与离线验收，未部署、未调用真实模型、未读取生产正文。

## 本次直接确认的边界

- 沿用现有聊天模型，先完成合成数据离线验收。真实模型成本上限、性能门槛和人工风格评分等待后续实测冻结，C-A08 不宣称生产达标。
- 可靠链路默认开启；显式设置 `FOUNDATION_ENABLED=0` 时拒绝聊天，不进入旧的未检查链路，不自动导入旧画像/历史。
- 同步移除 Android、Windows、Linux 聊天及互动界面的后台阶段文案；保留协议解析、内部状态、连接状态、消息失败和重试能力。

既有阶段 B 已确认的评分规则保持：明确稳定自述首次 0.6 正式；临时状态/计划首次 0.3 候选；同轮初次入库/晋级不额外叠加使用奖励。未映射历史、摘要与原始画像仍只供用户查看，不作为模型历史依据。

## C01–C04 实现

| 任务 | 实现与边界 |
|---|---|
| C01 | `public_policy.py` 集中 PRD-08 正文、版本和哈希；聊天、检查、重写、提取及既有后台任务实际请求携带公共约束。上下文分为当前输入、允许历史、正式用户事实、核验官方资料、原创日常；保留来源、事实修订、权限版本、主体和时间。未映射历史分区为空，保持阶段 B 的资格限制。 |
| C02 | `ReplyChecker` 在服务端检查最终清洗后的完整文字和提醒内容。七项检查为证据、主体、否定、时间、关系、重大事件、风格；校验断言原句、来源 ID 和真正使用的记忆。格式不合法、服务异常或重写仍失败均关闭交付；重写再次检查。回复摘要绑定最终正文与提醒，提交时验证一致性。 |
| C03 | 新输入为未交付轮次增加代次；旧草稿失效后重建同一逻辑轮次，同源消息不重复回答。每轮最多两份草稿，跨任务重试与进程恢复不重置。未发送的已提交回复可撤销，取消旧 outbox 并在同一事务补偿未成立的使用强化；独立提取证据保留。仅真正使用的正式命中参与强化。 |
| C04 | 首条源消息起 120 秒总预算，重试不重新计时；原 8/20 秒静默窗口保留，持续输入的攒批最多延至首条后 25 秒。内部持久化接受、攒批、生成、检查、提交、失败和投递观测。固定回放与故障/竞争测试覆盖有限收敛。 |

HTTP、WS、互动共用 `TextGenerator → ChatRuntime → ReliableChatStore`。正常生产装配启用 `require_checks=True`，因此升级前遗留的未检查待投递回复也不能通过 outbox 或历史同步首次交付。仓储层独立合成测试允许直接注入可信测试结果；这不是产品配置或回退开关。

官方版本变更、事实修订/权限变化、事实有效期，以及北京/东京跨日均有复核。图片保持既有原始字节链路；识图文字附模型来源标记，不能作为用户自述事实采集。

## 外发先后与恢复

按用户使用有界跨进程文件锁，序列化新输入接收、权限/事实变更、提取提交、最终提交及实际网络发送。模型调用只在开始外发时短暂占用协调锁，不占数据库长事务。网络发送有 5 秒上限；争用超限返回可重试失败，不谎报接收或禁用成功。

在发送锁内再次读取最新资格，先持久化发送意图，再执行 ASGI/WS 发送，成功后记录传输完成时间。若发送已开始，权限变更在该发送返回/失败后才能成功提交；禁用先提交，则后续发送复核失败。客户端 ACK 不是业务提交条件。发送开始后进程崩溃属于“交付不确定”，保留原消息 ID 重试，不能声称用户一定没收到。

HTTP 聊天回复、互动 REST 回复、WS 新投递/重复投递，以及历史同步首次取出待投递回复都经过这个边界。历史中已经交付过的消息继续作为历史展示，不进入模型。关停时等待短存储操作收敛，避免取消后线程继续占用数据库。

默认关闭旧主动问候及旧场景刷新调度；原创日常与主动消息的完整业务仍由 PRD-04/05 承接。

## 离线验收

| 验收项 | 本次证据 |
|---|---|
| C-A01 | 后续气泡、提醒文本、检查异常、检查缺项、未知证据来源、两次拒绝均不交付草稿；检查后改字不能提交。 |
| C-A02 | 上下文期间禁用、生成中禁用、检查中禁用、提交后禁用、发送期间禁用、北京/东京跨日；旧修订不能继续提交或首次交付。 |
| C-A03 | “不去→去”、多条追加同轮接续；代次失效旧草稿；持续输入不重置截止时间、不允许第三份草稿；8/20 秒规则与图片分轮回归。 |
| C-A04 | 写盘失败无假成功；重连/跨协议重投原 ID；未成立强化幂等补偿，独立证据不回滚；历史同步也不能旁路发送。 |
| C-A05 | 低分候选、禁用内容、旧摘要及 Bot 复述不进入聊天上下文；被检索但未真正使用的记忆不强化。 |
| C-A06 | 实际聊天、重写、检查、提取输入含相同公共正文/版本/哈希；既有后台摘要/场景等模型入口统一装配，静态入口检查通过。 |
| C-A07 | 检查不可用及预算耗尽收敛为失败；重连不重新生成已提交结果；固定失败文案不以“走神”“忘记”解释服务异常。三端隐藏阶段显示。 |
| C-A08 | 完成确定性回放与计时记录；真实模型语义质量、人工风格评分、成本与生产负载性能按本次确认继续待验收。 |

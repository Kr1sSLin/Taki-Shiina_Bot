## 最新规则与原 PRD 的差异

用户在语义样例复核时明确修改 S01、S07，并确认：**明确、稳定的自述首次 0.6 正式；临时状态或计划首次 0.3 候选，按新证据积累。** 这替代了原 PRD“普通新事实统一从 0.3 开始”的部分。测试中 M-A01 的四次表达阶梯现在对应临时状态/计划，不再要求稳定偏好先表达四遍。

| 场景 | 实际规则 | 决策状态 |
|---|---|---|
| 稳定偏好、明确既往事件、明确持续状态 | 新证据首次 0.6 正式；本轮选入回复仍保持 0.6 | 用户本轮最新确认 |
| 临时状态、计划 | 0.3 → 0.4 → 0.5 → 0.6；同轮最多一次 | 用户本轮最新确认 |
| 模型推断、第三人称、片段不匹配、来源不明旧数据 | pending，不因重复推断变成 accepted；默认权重 0 | 原 PRD 保留 |
| 纠正唯一的正式事实 | 同 factId、新 revisionId，重置 0.6，旧内容退出使用 | 用户看过角色对话范例后确认；S07 再确认 |
| 纠正唯一的临时候选 | 新修订重置 0.3 | 用户看过范例后确认 |
| 模糊冲突 | disputed 隔离，回复询问是变化还是之前记错；明确确认唯一项才解除争议，保留分数、阶段和权限 | 用户看过范例后确认 |
| 正常变化 | 结束旧状态适用范围，保留旧经历；新稳定偏好从 0.6、新临时状态从 0.3 独立记录 | 最新初值规则与原时间规则共同适用 |
| 禁用后重述或纠错 | 当前输入可以理解，原权限保持 blocked；禁止靠新 ID 恢复 | 原 PRD 保留 |
| “你记住”指令 | 没有独立的提分特权，计划仍从 0.3；稳定事实本身已有 0.6 初值 | 未启用额外例外 |
| 无用户输入的主动消息 | 不计正式使用加分；本期提交接口绑定真实用户来源 | O-09 实施默认 |
| 官方剧情范围 | 先交机制与公开可核验的小批样例；完整覆盖清单后续补齐 | 用户本轮明确选择 |

持续状态使用 `precision=ongoing`，只适用于有明确自述依据的住处、任职等持续状态。临时状态没有可靠截止时间时不能使用；计划没有适用时间时不能当成已完成。首次记录时间、源消息接收时间、事实有效时间和保留期限各自独立，旧记录没有首次记录时间时保持未知。

## 使用资格与上下文

用户事实需同时满足 owner、formal、weight ≥ 6、accepted、active、allowed、有效时间、保留期限与相关性。官方事实额外要求来源已核验、属于当前已发布剧情版本。分数既不是现实真伪概率，也不是权限。

生产运行时的接收入口设置 `memory_first`，聊天任务等当前批次提取任务到达终态后再组装上下文。提取事务独立提交，回复失败不会撤销用户的新证据。提取失败或因权限变化取消时，本轮不使用历史记忆，也不声称已完成记忆修改。底层仓储 `accept` 保留默认不等待提取的原型/测试模式；对外 HTTP/WS/互动均通过运行时启用前置处理。

O-03 按保守默认执行：原始跨轮聊天正文不供回复模型，界面仍可查看历史；当前逻辑轮次直接输入可用。通过正式筛选的事实才进入模型。尚未提供更宽的跨轮指代豁免，体验回放仍是阶段 C 的验收项。

正式使用加分只发生于最终成功尝试的上下文事实，且回复持久化成功。初始赋值、候选证据、纠错和争议解除占用同一轮次事实账本，避免同轮再次加分。失败/放弃的草稿、未选入的召回、事务回滚、无用户来源的主动任务均不产生正式使用加分；封顶 1。

## 权限、防复活与保守边界

- `enabled` 兼容旧协议，`modelPermission/permissionVersion` 独立表达权限；禁用保留真实分数、阶段与历史。
- 别名使用 keyed HMAC 身份索引，正文/来源/修订/账本仍沿用分域认证加密。旧客户端没有通用事实写回接口，不能绕过权限 CAS。
- 普通提取器只接收允许处理的事实。被禁用内容不会作为候选正文重新送入模型。当前重述命中禁用身份时只保留受控身份引用，既不加分也不新建同义记忆。
- owner 存在禁用用户事实时，已知、允许的其他候选仍可强化；无法证明身份关联的新条目进入 `memory_pending`。这里只保存源消息引用和原因，不另存禁用重述的记忆正文，也不自动授予新权限。
- 新官方条目使用稳定 entryId；已禁用条目发布新版本继承禁用。官方新身份存在未决权限关联时拒绝自动建档，须受控编辑复核。
- 历史正文不参与模型组装，旧画像/场景没有可核验来源时整体隔离；即使恢复某条事实，也不会自动重新放开这些旧派生内容。
- 禁用或修订发生在生成过程中时，后续调用与提交被拒绝；发生在保存后、交付前时，outbox 读取及 HTTP/WS 结果轮询都重新检查。已发给外部模型的数据不能撤回。
- 备份沿用阶段 A 的一致快照和恢复门闩。缺少外部可信最新水位时保持关闭；本期未执行生产备份恢复。
- 明确删除请求只承诺停止使用，并说明尚未支持彻底删除原聊天与备份，不伪称已删除。

自然命令支持明确的“以后别再提 X / 停止使用 X / 恢复使用 X / X 可以重新记着了 / 删除 X”。通过当前直接给出的别名或最近轮次唯一来源定位；多对象/批次指令不明确时询问，不批量恢复。复杂同义表达仍需语义回放扩充，不能把窄语法支持冒充任意自然语言理解。

## 外部接口

| 接口 | 行为 |
|---|---|
| `GET /api/v1/memory/facts?cursor=0` | 沿用事件游标分页；增加 score、stage、truthStatus、revisionStatus、modelPermission、permissionVersion、revisionId 和时间字段；禁用列表正文为空 |
| `GET /api/v1/memory/facts/{factId}` | 只按认证 owner 读取详情和证据片段，返回 `Cache-Control: no-store`；供本人管理，不是模型检索接口 |
| `PATCH /api/v1/memory/facts/{factId}/permission` | `{enabled: boolean, expectedRevision: integer}`；成功返回新修订与权限；晚到版本 409，越权 403，存储失败 503，不发送虚假成功 |

官方版本编辑接口只在仓储的受控编辑流程开放，没有给普通聊天用户授予官方核验权限，也没有自动抓取、自动发布或生产定时任务。

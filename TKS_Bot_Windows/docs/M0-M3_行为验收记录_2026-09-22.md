## 已确认需要修复的问题

1. **托盘图标资源缺失**：`TKSDesktop/Platform/Windows/TrayIconManager.cs:146` 读取 `Resources/Assets/tks-desktop.ico` 的 pack URI；`TKSDesktop/TKSDesktop.csproj` 只用 ApplicationIcon 嵌入 EXE 图标，没有将 ICO 打成 WPF Resource。实际发布 `TKSDesktop.g.resources` 的 13 项全部是 BAML。
2. **设置页只读属性双向绑定**：`SettingsView.xaml:48/51/54/111/113/137/139` 的主题、关闭行为、发送键 RadioButton 绑定只读属性；后两组也没有切换命令。另 `:118` 用 bool 转换器绑定 Visibility。
3. **缩放参数未生效**：产品代码只有 `CliOptions.ForceDeviceScaleFactor` 的解析，无应用点；现有自检只证明参数解析。
4. **显示器变化及混合 DPI 校正缺失**：`WindowChromeService.EnsureOnScreen` 用 WPF DIP 与 GetMonitorInfo 的像素工作区比较；无 DisplaySettingsChanged / WM_DISPLAYCHANGE / WM_DPICHANGED 处理路径。
5. **输入焦点保证不足**：`MainWindow.ActivateAndFocus` 及 FocusInputRequested 使用 ChatPane.Focus()，未使用已有的 ChatPane.FocusInput()。完整的快捷键“唤起并聚焦输入框”仍需验证。

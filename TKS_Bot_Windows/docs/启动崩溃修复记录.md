# Windows 启动崩溃修复（2026-09-22）

Windows 事件日志中的 `0xe0434352` 来自登录窗口首次布局的未处理异常：`Double 10` 被用作 `Border.CornerRadius`。

## 修复

- `Tks.Radius.*` 改为 `CornerRadius`；`Tks.Space.*` 的所有当前使用点均为 Margin/Padding，因此同步改为 `Thickness`。字体尺寸仍为 Double。
- 修正历史页、提醒页四处包含五个数值的无效 Margin。
- 窗口测试实际 Show/UpdateLayout 登录和主窗口，并对六个主要页面、用户和助手消息气泡进行 Measure/Arrange/UpdateLayout。
- 启动入口捕获异常，通过脱敏日志记录异常并显示本地化失败提示，返回非零退出码。
- 发布脚本调用 `scripts/smoke-startup.ps1` 检查发布目录的真实 EXE：隔离凭据/数据、启动正常入口、观察窗口与存活状态、核对登录窗口完成初始布局的日志。检查结束后只停止测试创建的进程，临时日志保留。

## 使用

```powershell
.\scripts\verify.ps1
.\build.ps1
.\scripts\smoke-startup.ps1 -Executable '实际安装目录\TKSDesktop.exe'
```

运行启动检查前需关闭已有客户端，因为正常入口保留生产单实例行为。

## 安装目录说明

NSIS 支持用户选择安装目录。桌面路径与默认 LOCALAPPDATA 路径不同，并不证明存在旧快捷方式或安装错误。应以实际安装目录和快捷方式目标是否一致为准；无需仅因此卸载或删除用户数据。

新安装包不会自动替换用户已安装的程序；需要运行新安装包更新。发布版启动检查及 WPF 布局测试不等同于安装后 Toast、自启、多屏或真实后端交互验收。
